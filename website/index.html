A FEW DETAILS

Good to know.

Does LocalOps need a cloud account?

No. LocalOps reads system metrics locally. History is held in memory for the current session. There is no account or hosted monitoring service to configure.

Can LocalOps remove files?

Analysis is read-only. You can review and move selected items to the system trash; emptying the trash requires confirmation. On macOS you can also review apps and possible associated files. LocalOps does not terminate processes.

Can I use it in Chinese?

Yes. The app follows your system language by default. Choose System default, 中文 or English in Settings and save to persist your preference.

Can I look under the hood?

Absolutely. LocalOps is MIT-licensed and built with Go, MyGo and TypeScript. Read the code on GitHub ↗
